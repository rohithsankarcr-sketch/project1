# AYAS: THE LAST WARD - Audit Report

## Engine
- Web-based (Three.js) - both root js/ and PlayablePrototype/js/ exist
- HTML/CSS/JS
- Deployed via Vercel (vercel.json present)

## Current Systems
- First-person movement, sprint/crouch, mouse look
- Flashlight, AYAS detector, calibration
- Yakshi AI with states (Dormant/Stalking/Hunting/Searching/etc.)
- 3 wards, evidence, journal, quests
- Hiding spots, sacred ash
- Health/damage added recently
- Limited pursuit, concussion on jumpscares
